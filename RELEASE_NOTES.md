# Parkly 1.3

- Демо-парковки Алматы стоят на настоящих парковках и улицах из OpenStreetMap
- Новая чёткая карта с подписями по-русски
- Все парковки — одинаковые аккуратные метки, кластеры не закрывают карту
- Пин отвечает на вопросы про цену, места, часы работы и «рядом со мной»
- Экран Пина больше не просвечивает картой, поле ввода прижато к клавиатуре
- Сайт и обновления работают с GitHub — без локального сервера
